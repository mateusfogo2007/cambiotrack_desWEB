## Descrição
Painel financeiro que exibe cotações de USD, EUR e BTC em tempo real (AwesomeAPI) e permite simular ordens de câmbio com spread de 2%, listar, cancelar e excluir transações, com indicadores consolidados.

## Tecnologias
HTML5 semântico, CSS3 puro (Flexbox, Grid, Media Queries), JavaScript ES6+ (POO com campos privados, async/await, Fetch API).

## Como executar
1. Baixe e descompacte o projeto.
2. Abra a pasta no VS Code e rode com a extensão **Live Server** (botão direito em `index.html` > *Open with Live Server*), ou apenas abra `index.html` no navegador.
3. É necessário internet para carregar as cotações.
